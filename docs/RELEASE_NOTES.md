# 更新说明

## 0.2.0

### 输入与任务

- 分离语音润色和 AI 对话快捷键，默认分别为 `Ctrl+Alt+R`、`Ctrl+Alt+A`。
- 润色默认修正语病、语境明确的成语误用和不当措辞，精简冗余并保留事实与立场；不执行口述请求。
- AI 对话支持同一任务多轮语音澄清，只有最终正文自动输入。
- 单行使用 Unicode 输入，多行写剪贴板后一次粘贴，不模拟 Enter/Shift+Enter，不自动发送消息。
- 结果输入完成时的当前活动位置，不检查或恢复焦点，不检查密码框。
- 单实例保护；取消、超时和迟到结果隔离。

### 设置与服务

- OpenAI-compatible multipart ASR、MiMo 音频 Chat Completions ASR，以及兼容 Chat Completions 的 LLM。
- 两用途业务提示词独立编辑和恢复默认，单一背景字段；每项最多 16000 个 Unicode 字符。
- 可选 Exa 搜索仅用于 AI 对话；搜索次数和工具轮数分别配置，模型请求上限为工具轮数 + 1。
- 配置位于 EXE 同级 `config.json`，缺失时验证并迁移旧 AppData 配置，保留源文件；密钥仍在 Credential Manager。
- 设置加载、保存草稿和连接测试相互隔离，失败保留编辑，不回显密钥。

### 界面

- 设置使用桌面分类侧栏，窄窗口切换顶部分类，保存栏固定。
- 原生非激活置顶浮窗按工作、澄清和阅读阶段展开，真实音量驱动声波。
- 同源声波图标；复制和补充操作常驻底栏，空正文不占位。
- 最终正文出现时跟随一次，用户回看后不反复抢滚动；新问题优先显示问题区。
- 终态默认保留 30 秒，鼠标交互后保持到手动关闭。支持时尝试 Windows 11 窄外缘材质，不支持时实色回退。

## 当前限制

- 未签名，无安装器、自动更新器或 WebView2 自动安装引导。
- 麦克风、驱动、输入法、多屏 DPI、原生外观、各应用粘贴行为及真实模型质量需按环境验证；交叉编译和浏览器 fixtures 不代表实机通过。
- 自动输入最多 8000 字，不支持 Tab 等控制字符；部分提交不自动重试。
- 多行输入和复制会替换剪贴板，目标应用可能自行执行粘贴内容。
- 不提供录音/转录历史、跨任务长期记忆、任意工具/MCP、TTS、长按录音或自动发送。
- 原生驱动调用不能被 Go context 强制终止，失去响应的设备可能需要重启应用。

详细行为与迁移注意事项见[使用指南](USER_GUIDE.md)，测试范围见[测试矩阵](TEST_MATRIX.md)。
