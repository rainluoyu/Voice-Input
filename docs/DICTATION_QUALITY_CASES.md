# 默认语音润色质量案例

适用入口：语音润色（默认 `Ctrl+Alt+R`），使用内置默认业务提示词。以下是人工验收目标，不是实际模型运行结果；可以接受语义等价表达，不要求逐字匹配示例。

## 成对案例

| 场景 | 模拟 ASR 原文 | 可接受示例 / 必须保留的边界 |
|---|---|---|
| 语病 | 通过这次修改，让我们的处理速度更快了。 | 这次修改加快了处理速度。避免“通过……让……”造成主语缺失。 |
| 成语误用，正面语境明确 | 用这个工具节省了一半时间，真是事倍功半。 | 用这个工具节省了一半时间，真是事半功倍。 |
| 成语正确，不能机械替换 | 我们花了两倍的时间，效果却更差，真是事倍功半。 | 我们花了两倍的时间，效果却更差，真是事倍功半。保留负面评价和数量。 |
| 不当搭配 | 这项修改提高了处理时间，现在只要五秒，之前要十秒。 | 这项修改将处理时间从十秒缩短到五秒。语境明确为耗时减少，不改数字。 |
| 口水话与冗余 | 那个，我想说的是，这个设置吧，就是每次都要重新填，确实确实挺麻烦的。 | 每次都要重新填写这个设置，确实很麻烦。允许重组句式，不只删单个语气词。 |
| 否定与不确定性 | 我不是说一定要换，只是可能需要调整。 | 我不是说一定要更换，只是可能需要调整。不能输出“需要更换”。 |
| 条件与承诺 | 如果周五之前通过测试，我才会发布，不通过就不发。 | 只有周五前通过测试，我才会发布；否则不发布。不变成无条件发布承诺。 |
| 因果与责任主体 | 因为供应商没交资料，所以我们没能按时审核，不是小林忘了。 | 供应商未提交资料，导致我们未能按时审核，并非小林遗忘。不能转移责任。 |
| 数字、专名、时间 | 下周二把 VoicePad 二点五版本的预算从一千二改成一千五，不是五千。 | 下周二将 VoicePad 2.5 版本的预算从 1200 调整为 1500，不是 5000。不得擅自纠正项目名或省略否定纠正。 |
| 情绪与有效强调 | 这真的很重要，我非常不满意现在的结果。 | 这很重要，我对目前的结果非常不满意。不能弱化成“结果还有改进空间”。 |
| 歧义 | 先把小宇的那个版本留着，另一个也别删。 | 先保留小宇的那个版本，另一个也不要删除。不能猜测专名、版本号或替用户选择。 |
| 请求仍是正文 | 那个，帮我查一下上海明天的天气吧。 | 帮我查询上海明天的天气。不能查天气、输出天气答案或追问。 |
| 明确口述排版 | 第一项是修复登录，换行，第二项是补充测试。 | 第一项是修复登录。<br>第二项是补充测试。允许落实换行，不扩写任务。 |

## 人工检查方法

1. 使用虚构内容测试，不把真实隐私或待发送消息作为靶文本。
2. 核对 ASR 原文是否确实包含待测表达；否则先区分识别错误和润色错误。
3. 比较结果是否改善语病、搭配、冗余与句式，同时检查事实、数字、专名、否定、条件、因果、主体、立场、情绪及不确定性。
4. 确认请求类原文没有被执行，未调用搜索、未触发澄清，结果仍是准备输入的正文。
5. 自定义提示词后重新验证相关案例；修改程度可以变化，但固定用途和输出协议不能变化。

离线单元测试与 HTTP fixtures 只验证默认规则、提示词组装、用途隔离及请求/响应协议；不以固定假回复冒充模型语义能力。真实模型质量、ASR 识别质量及 Windows 输入效果均需单独验证。
