# 测试矩阵

测试区分纯逻辑/本地 fixtures、跨平台编译与 Windows 实机行为，不将其中一种结果当作另一种的证明。普通回归不启用真实服务。

## 自动回归范围

| 范围 | 位置 | 验证内容 |
|---|---|---|
| 任务状态 | `internal/app` | 录音、处理、终态、取消、超时、迟到结果、TaskID/Turn/Revision、配置显示时长（默认 30 秒）及交互常驻 |
| 用途与澄清 | `internal/pipeline`、`internal/app` | 双用途隔离、同任务补充历史、轮次限制、未完成任务保护 |
| 音频 | `internal/audio` | PCM16/24/32/float、声道与跨块重采样、WAV、静音/短音频、时长边界 |
| ASR | `internal/asr` | multipart/MiMo 请求、格式与大小限制、Probe、错误脱敏；使用本地 HTTP 服务 |
| LLM 与搜索 | `internal/llm`、`internal/search` | 严格输出、提示词组装、用途隔离、工具批次/搜索/模型请求预算、证据裁剪及错误处理 |
| 网络 | `internal/netapi` | 地址、代理、回环直连、重定向拒绝、JSON 严格解析及错误边界 |
| 语言 | `internal/i18n`、`internal/llm`、`internal/app` | 系统语言匹配/回退、双语词典、默认规则与请求一致、应用消息来源隔离、任务语言快照 |
| 配置 | `internal/settings` | 兼容读取、Unicode/容量、显式零预算、EXE 路径、迁移优先级、不覆盖发布、失败清理与原子保存 |
| 输入 | `internal/wininput` | 单行/多行规范化、Unicode、字符与长度限制、粘贴提交逻辑；真实系统调用另测 |
| 快捷键/单实例 | `internal/hotkey`、`internal/instance` | 两键等价冲突、更新/回滚、平台契约；Windows 生命周期另测 |
| 浮窗 | `internal/popup` | 布局、阶段尺寸、DPI 工作区夹紧、音量条、正文一次跟随及问题滚动优先级 |
| 图标 | `internal/branding`、`tools/winresource` | 前端 PNG 与托盘同源、资源/manifest |
| 设置 UI | `tests/frontend_settings.py` | 加载门控、草稿、保存竞态、服务测试、密钥操作与错误保留 |
| 通用设置 | `internal/settings`、`internal/startup`、`internal/app`、`internal/audio`、`internal/pipeline`、`tests/frontend_settings.py` | 旧配置默认关闭、管理员子选项联动、保存失败补偿、自动复制与输入独立、静音状态恢复、显示时长范围及任务快照；系统集成另测 |
| 浏览器渲染 | `tests/frontend_smoke.py`、`tests/frontend_bridge.py` | 响应式、键盘导航、对比度、阶段状态、复制反馈、滚动、旧快照与安全文本渲染 |
| 打包 | `tools/package` | 明确成员白名单、配置/内部资料排除、PE/manifest、许可证及 SHA-256 |

命令与环境见[开发指南](DEVELOPMENT.md)。Go race 不证明跨进程文件访问完全没有竞争；编译成功不证明原生 ABI 在运行时正确。

## Windows 人工回归

准备：普通权限运行当前构建，使用虚构内容与临时编辑器；必要时使用 `tests/target.html`。不要用真实密码、私人语音或待发送消息。每次实测自行记录 Windows/WebView2/目标应用版本与观察结果，私人记录不要提交仓库。

| 场景 | 预期 |
|---|---|
| 完整配置启动、重复启动 | 托盘常驻；单实例重复启动退出，不抢焦点；配置缺失时打开设置 |
| 两套快捷键 | 对应用途开始/结束；未完成任务不被另一用途替换或停止 |
| 真实录音与 ASR | 设备、电平、静音/短音频、断开与超时正确；不虚构转录 |
| 润色与 AI 对话 | 润色只整理口述正文；AI 执行请求，需要时提问 |
| 澄清补充 | 原始请求和问答保留在同任务；补充失败可重录；只有最终结果输入 |
| 切换活动位置 | 处理完成后输入新的活动位置；不恢复原窗口，不检查密码属性 |
| 单行 Unicode | 中文、emoji 完整；未开启结果自动复制时，自动输入不修改剪贴板 |
| 多行/空行/代码 | 替换剪贴板后一次粘贴，不按 Enter；检查目标应用自身的粘贴行为 |
| 结果自动复制 | 默认关闭；开启后 ASR 原文与正文分阶段复制，单行也替换剪贴板；输入失败不阻止复制，复制失败明确提示 |
| 登录自启动 | 普通启动、管理员启动、关闭可切换；取消 UAC 或使用其他账户授权时不保存，保存失败恢复原注册；移动 EXE 前先关闭自启动 |
| 录音静音播放 | 默认关闭；开启后录音期间静音默认播放端点，停止、取消、失败及退出时恢复原静音状态 |
| 取消、超时、部分失败 | 迟到结果不输入；已有文本可复制；部分提交不盲目重试 |
| 浮窗与滚动 | 右下角、置顶不激活；阶段尺寸合理；结果跟随一次，回看不被重复状态打断 |
| 结果显示时长及保持 | 默认 30 秒，可设为 1–3600 秒；未交互终态按任务快照的时长隐藏，移入/点击/滚动后保持；等待澄清不超时 |
| 多屏、DPI、系统材质 | 工作区夹紧、按钮命中、可读性、材质失败回实色；不为外观激活 |
| 设置与快捷键修改 | 草稿不丢；失败不覆盖；冲突或回滚失败明确提示 |
| 中英文与系统语言 | auto 按 Windows 偏好解析，保存后托盘/原生同步；英文按钮和多 DPI 不截断；切换不抢焦点或重启结果跟随；用户/模型中文不被翻译 |
| 同级配置迁移 | 不依赖 cwd；仅同级缺失时迁移，旧文件不变；已有无效目标不覆盖 |
| 权限和密钥 | 不可写目录不回退/提权；凭据不进 JSON，跨用户复制配置不带密钥 |
| 系统/应用兼容 | 输入法、睡眠恢复、设备重连、编辑器、浏览器、终端分别检查；权限拦截明确失败 |
| 无开发环境启动 | WebView2、托盘、普通权限 manifest、未签名提示与完整退出 |

以上是当前产品的验收清单，不是一份已全部通过的实机报告。当前构建、设备与目标应用必须分别验证。
