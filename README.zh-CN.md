# 真实语义输入 · True Semantic Input

[English](README.md) | **中文**

Windows 语音输入工具：用不同快捷键选择**语音润色**或 **AI 对话**，把口述整理成文本，或直接生成请求所需的正文。结果输入处理完成时的当前活动位置。**不自动按 Enter，不额外发送消息。**

采用 Go、Wails、TypeScript 和不激活的原生 Win32 浮窗，应用界面目前为中文。

## 功能

- **语音润色**：修正语病、语境明确的成语误用和不当措辞，精简口水话与冗余，保留事实、意图和不确定性；不执行口述请求。
- **AI 对话**：写作、翻译、回答或生成代码；遇到澄清问题时，可在同一任务中继续语音补充。
- **自定义提示词**：两种用途独立编辑和恢复默认，可填写额外背景信息。
- **可选 Exa 搜索**：仅 AI 对话使用，搜索次数和工具轮数分别设定；工具轮数为 0 时禁用工具。
- **单行与多行输入**：单行直接 Unicode 输入，多行及代码通过剪贴板粘贴，不模拟 Enter/Shift+Enter。
- **桌面交互**：托盘、可编辑全局快捷键、麦克风选择、真实音量反馈、单实例及不抢焦点的置顶浮窗。
- **同级配置**：`config.json` 位于 EXE 旁，API 密钥单独保存在 Windows 凭据管理器。

## 运行要求

- Windows 10/11 x64。
- Microsoft Edge WebView2 Evergreen Runtime。
- 麦克风及已配置的 ASR 服务；AI 处理需要 OpenAI-compatible Chat Completions 服务，Exa 可选。
- 用户可写的程序目录，使用普通权限运行，不要以管理员身份启动。

ASR 支持 OpenAI-compatible multipart 转录和 MiMo 音频 Chat Completions 协议，另有 ASR 直通诊断模式。服务兼容性和转录质量取决于配置的供应商。

## 快速开始

1. 按下文从源码构建，或将可信的便携包解压至可写目录。
2. 启动 `voice_input.exe`，从托盘打开设置；服务配置不完整时会自动打开设置。
3. 保存服务地址、模型和 ASR 协议，再单独保存对应密钥。“测试连接”使用已保存的配置，可能产生服务费用。
4. 在临时文本编辑器定位光标，用同一快捷键按一次开始录音，再按一次停止：

   | 用途 | 默认快捷键 | 口述“帮我写一封请假邮件” |
   |---|---|---|
   | 语音润色 | `Ctrl+Alt+R` | 润色请求本身，不生成邮件 |
   | AI 对话 | `Ctrl+Alt+A` | 生成邮件正文 |

5. AI 提出澄清问题后，使用 AI 对话快捷键或浮窗的补充按钮录制回答。

未完成任务不能被另一用途的快捷键替换或停止。关闭浮窗会取消任务；关闭设置不会退出程序，完全退出请使用托盘菜单。

## 配置与预算

- 活动配置固定为 **EXE 所在目录的 `config.json`**，不依赖工作目录或快捷方式位置。
- 同级文件缺失时，校验并迁移旧 `%APPDATA%\voice_input\config.json`，旧文件原样保留，后续只保存新文件。同级配置无效时不会被迁移覆盖。
- 两处都不存在时，默认值先保留在内存，保存后才创建文件。目录不可写时明确失败，不提权、不退回 AppData。
- 彻底重置前先退出程序，备份并移开两处配置；只移开同级文件可能再次导入旧配置。
- 两份自定义提示词及背景各最多 16000 个 Unicode 字符，配置 JSON 总容量上限 512 KiB。可编辑规则不替换固定输出协议、用途边界或工具权限。
- 每轮处理：搜索次数默认 2 次（1–8），工具轮数默认 2 轮（0–8），模型请求最多为工具轮数 + 1。每次澄清补充分别开始新的处理预算，不是整项任务的累计费用上限。

## 隐私与输入安全

- **不检查焦点、目标窗口或密码框属性。** 结果进入处理完成时的当前活动位置，请自行确认目的地。
- 多行自动输入和手动复制都会**替换剪贴板，不恢复旧内容**。剪贴板历史、同步和第三方管理器可能保留文字；即使程序不按 Enter，目标应用也可能自行提交或执行粘贴内容。
- 自动输入最多 8000 字（规范化换行后计数）。不支持的控制字符或输入失败会保留文本供复制；部分输入后不要盲目重试。
- 音频和文字在内存处理，应用不保存录音或转录历史。音频发送到配置的 ASR；AI 处理会将转录、所填背景及相关补充历史发送到配置的 LLM；可选搜索将模型选择的查询发送给 Exa。各供应商有独立的数据留存政策。
- 配置可能包含私人背景和提示词，分享前请检查。密钥单独存入当前 Windows 用户的凭据管理器，复制 JSON 不携带密钥；这不防御同一用户下运行的恶意软件。
- 完成结果默认保留 30 秒；鼠标交互后保持至手动关闭，等待澄清不超时。WebView2 和操作系统可能自行保存缓存。

先在临时编辑器或附带的 `tests/target.html` 中使用虚构内容测试，不要使用真实密码或待发送消息。

## 从源码构建

使用 Go **1.26.9**（由 `go.mod` 选择）和 Node.js **22.12+**。Wails/runtime 锁定为 `v3.0.0-beta.30`。

在 Windows 终端的仓库根目录执行：

```powershell
npm --prefix frontend ci
npm --prefix frontend run build
go run ./tools/winresource
go build -trimpath -ldflags="-H windowsgui" -o bin/voice_input.exe ./cmd/voice_input
.\bin\voice_input.exe
```

持久配置测试应先构建再运行：`go run ./cmd/voice_input` 的 EXE 位于临时目录，配置位置也会随之改变。

Linux/WSL 可构建前端、运行离线测试和交叉编译 Windows 程序，不提供 Linux 桌面应用。检查、浏览器 fixtures 和便携打包见[开发指南](docs/DEVELOPMENT.md)。

## 测试与限制

Go 单元/race、本地 HTTP fixtures 和隔离浏览器测试覆盖状态管理、协议校验、设置、工具预算、渲染和配置迁移，但不能证明麦克风/驱动兼容性、原生焦点行为、DPI/材质外观或真实模型语义质量。Windows 专项测试程序需另在 Windows 执行。构建未签名，不包含 WebView2 安装器。

真实服务集成测试必须显式启用，可能产生费用，不属于普通回归。
